# Doctor-Friendly Liver Disease Dashboard

This is a code bundle for Doctor-Friendly Liver Disease Dashboard. The original project is available at https://www.figma.com/design/6FXrdbG2giBIC1HMnJ0qL4/Doctor-Friendly-Liver-Disease-Dashboard.

## Doctor-Friendly UI Dashboard
A React + Vite based clinical dashboard designed for doctors to input patient parameters
and view liver disease risk predictions with visual explanations and charts.
The interface focuses on clarity, accessibility, and clinical usability.

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
